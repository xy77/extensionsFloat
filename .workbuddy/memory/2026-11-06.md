## 补全 Windows 安装流程 + 插件功能清单

- Windows Native Messaging host 方案选型：Chrome 在 Windows 上允许 host manifest 的 `path` 指向非 exe（走 cmd.exe legacy 路径，Chromium 为批处理/python 保留），因此用 `.cmd` 启动 PowerShell，**不编译 exe、不引入任何依赖**。注册表写 HKCU（免管理员）。
- 关键设计：宿主文件（host manifest / 启动器 / entry.ps1 / config.json）统一放在 `%LOCALAPPDATA%\FloatExtension\`，与插件目录隔离。updater 替换插件目录时不会破坏注册；entry.ps1 每次启动把插件目录里最新的 `native-host/updater-windows.ps1` 复制到外部再执行，避开 Windows 下「删除正在执行的脚本」的文件占用问题。
- 安装体验：解压 → Chrome 加载 unpacked → 复制 Extension ID → 双击 `scripts/install-windows.cmd` 粘贴 ID → 自动写注册表并做一次 `ping → pong` 自检。卸载双击 `scripts/uninstall-windows.cmd`。
- 新增：`native-host/updater-windows.ps1`（stdio 协议 + ping/check/update + 下载/sha256/备份/保留/回滚）、`scripts/install-windows.ps1`、`install-windows.cmd`、`uninstall-windows.cmd`、`.gitattributes`（`*.cmd text eol=crlf`）。`*.cmd` 必须 CRLF；含中文的 `.ps1` 必须 UTF-8 带 BOM（PowerShell 5.1 否则按 ANSI 读）。
- 修改：README 增加「功能一览」+ Windows 首次安装/FAQ；`src/updater/nativeHost.js` 错误文案改跨平台；`manifest.json` 1.0.22 → 1.0.23 以触发发版。
